# 基于结构化检索与深度搜索的 Agent 论文解读报告

## 一、研究背景

随着大语言模型（LLM）被广泛应用于知识密集型问答与复杂推理任务，其**知识静态性**与**外部信息整合能力不足**的问题日益凸显。  

传统 RAG 方法以文本块检索为核心，忽略了结构化知识（如知识图谱）与动态网页环境中的深层信息关系，在多跳推理、证据覆盖与搜索深度方面存在明显瓶颈。

近年来，研究开始探索：
- **结构化检索（Graph / Subgraph）**以提升证据完整性  
- **自主搜索 Agent** 通过多步工具调用完成“研究型”任务  
- **强化学习（RL）** 用于优化 Agent 的搜索与推理策略


## 二、SubgraphRAG（ICLR 2025）

### 2.1 动机
- 传统 KG-RAG 依赖路径或局部结构，证据覆盖不足  
- 固定形式子图（如路径）难以支持复杂多跳推理  
- 多轮 LLM 调用进行 KG 搜索，计算开销大、延迟高  

### 2.2 核心贡献
- 提出 **SubgraphRAG**：以“灵活子图”作为检索单元的 KG-RAG 框架  
- 并行打分与抽取三元组，避免路径约束  
- 引入 **方向距离编码（Directional Distance Encoding）** 表征结构信息  
- 检索与推理解耦：轻量检索器 + 强推理 LLM

### 2.3 工作流程
1. 主题实体（Topic Entities）抽取  
2. 构建以主题实体为中心的候选子图  
3. 并行评估三元组相关性，抽取 Top-K 证据  
4. LLM 在子图上完成多跳推理与回答生成  

### 2.4 实验结论
- 在 WebQSP、CWQ 等多跳 KGQA 基准上显著优于路径型方法  
- 子图规模可调，适配不同 LLM 的上下文与推理能力  
- 在检索效率与推理性能之间实现良好平衡  


## 三、WebSailor-V2（arXiv 2025）

### 3.1 动机
- 现有开源 Web Agent 与闭源系统（如 DeepResearch）存在显著性能差距  
- 复杂 Agent 框架与重 Prompt Engineering 掩盖模型真实能力  
- RL 训练中，**高质量数据与稳定环境**比算法本身更关键  

### 3.2 核心贡献
- 提出 **WebSailor-V2**：基于标准 ReAct 的深度搜索 Agent  
- 构建 **SailorFog-QA-V2**：真实网页驱动的高复杂度研究型数据集  
- 数据构建与 RL 训练形成“共进化”闭环  
- 证明中等规模开源模型可超越超大闭源 Agent

### 3.3 Agent 与工具体系
- 基于 **ReAct（Thought–Action–Observation）** 框架  
- 四类核心工具：
  - Search（网页搜索）
  - Visit（网页访问与摘要）
  - Google Scholar（学术检索）
  - Python Interpreter（计算与分析）
- 不依赖复杂计划或提示工程

### 3.4 实验结果
- 在 BrowseComp-EN / ZH、HLE 等基准上显著领先开源 Agent  
- 30B 模型性能超越 671B 的 DeepSeek-V3.1  
- 案例分析显示 Agent 具备：
  - 线索拆解
  - 搜索策略自我修正
  - 系统化交叉验证能力  


## 四、总结

这两项工作从 **结构化知识检索** 与 **动态网页搜索** 两个方向，展示了下一代 Agent 的关键能力跃迁：

- 从“检索文本”走向“构建证据结构”
- 从“回答问题”走向“执行研究”
- 强化学习在 Agent 行为策略与工具调用中的核心作用
- 简洁通用框架 + 高质量数据，优于复杂人工设计

整体来看，**结构化子图检索 + 深度搜索 Agent + RL 训练**，正在共同塑造真正具备“研究能力”的通用智能体。
