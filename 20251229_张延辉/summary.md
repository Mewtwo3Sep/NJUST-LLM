# 组会报告总结（DeepResearch & DeepEyes 系列）

## 一、报告背景
本次组会主要围绕 **基于强化学习的 Research Agent** 展开，系统梳理了 **DeepResearch** 与 **DeepEyes** 两个系列工作，重点关注多模态场景下 Agent 的 **任务规划、工具调用与强化学习训练范式**。

---

## 二、DeepResearch 系列论文总结

主要介绍WebWatcher论文内容

### 1. 研究动机
- 传统 Deep Research Agent 以文本推理为主，忽视真实世界中的 **视觉信息**
- 多模态复杂任务需要：
  - 图像理解  
  - 跨模态推理  
  - 多工具协同  

### 2. 核心框架
- **任务规划 → 多轮工具调用 → 交叉验证 → 精确回答**
- 典型能力：
  - 迭代推理
  - 结构化写作
  - 多工具协作（搜索、图像检索等）

### 3. 数据构造
- 构造流程：
  - 复杂文本 QA → VQA → 带工具调用的推理轨迹
- 数据集：
  - BrowseComp-VL（10 万样本）
    - Level-1：明确实体
    - Level-2：模糊实体
- 借助 GPT-4o 生成 **ReAct 风格轨迹**
- 严格过滤：
  - 最终答案一致
  - 推理步骤一致性
  - ≥3 次工具调用，避免“捷径解”

### 4. 训练策略
- **Cold-start SFT**
  - 使用约 8k 条高质量轨迹
  - 教会模型任务理解与基础工具调用
- **强化学习（GRPO）**
  - K=16 条轨迹采样
  - 设计准确性与稳定性奖励

### 5. 实验结论
- 复杂问题 **必须依赖工具调用 + 多步推理**
- 结论对比：
  - 纯模型推理：不可用
  - RAG：知识问答提升，但推理有限
  - Reasoning Model：推理增强但缺乏工具
  - Agent：最优，多步复杂任务表现最佳
- **SFT 是 RL 成功的必要前提**

## 三、DeepEyes 系列论文总结

### 1. 研究目标
- 让模型在推理过程中 **“像人一样用图像思考”**
- 视觉信息不再是静态输入，而是动态参与推理

### 2. 研究动机
- 工具调用能力弱：
  - 无法组合多类工具
  - 容易退化为短回答或 reward hacking
- 人类式问题解决流程难以复现：
  - 观察 → 搜索 → 计算 → 推理

### 3. 方法框架
- 训练流程：
  - Cold-start SFT + RL（DAPO）
- 工具类型：
  - 图像裁剪 / 放大
  - 搜索工具
  - 代码计算工具

### 4. 数据准备
- 感知类数据：依赖视觉工具
- 推理类数据：数学与代码计算
- 搜索类数据：依赖联网检索
- Long CoT：纯文本复杂推理
- 样本筛选：
  - 剔除基础模型可直接解决的问题
  - 保证工具调用带来显著收益

### 5. 实验结果
- **RealX-Bench**
  - 人类：70.0%
  - Gemini 2.5 Pro：46.0%
  - DeepEyesV2：28.3%
- 在 **Search & Integration** 子任务中提升显著
- 消融实验表明：
  - 多样化数据 + Long CoT 对模型能力至关重要
- RL 后模型学会：
  - 仅在必要时调用工具
  - 自适应控制推理深度与调用次数

---

## 四、整体结论与启示
1. **Research Agent 的核心不只是推理能力，而是“何时、如何使用工具”**
2. Cold-start SFT 是多模态 Agent 强化学习的关键前置条件
3. 多模态、多工具、多任务的数据多样性决定了 Agent 的泛化能力
4. 强化学习的价值在于：
   - 学会策略选择
   - 抑制无效工具调用
   - 提升整体推理效率与稳定性
