# 基于强化学习的 Agent 论文解读报告

## 一、研究背景

大语言模型（LLM / LRM / MLLM）在复杂、知识密集型任务中面临知识静态、外部信息整合能力不足的问题。  

传统 RAG 与检索型 Agent 在灵活性、搜索深度和推理能力方面均存在明显局限。



## 二、WebThinker（NeurIPS 2025）

### 2.1 动机
- 模型依赖内部静态知识
- RAG 流程固定，无法动态补充知识
- 检索 Agent 仅能获取浅层信息

### 2.2 核心贡献
- 提出 WebThinker：深度网页探索 + 推理端到端融合
- Deep Web Explorer：支持多层网页导航
- Think–Search–and–Draft：推理、搜索、写作动态交织

### 2.3 工作模式
- Problem-Solving Mode
- Report Generation Mode

### 2.4 实验结果
- 自主搜索 Agent 显著优于 RAG
- RL 训练进一步提升性能
- 在科学报告生成任务中，完整性与深入性显著领先



## 三、DeepMMSearch-R1（arXiv 2025）

### 3.1 动机
- MLLM 知识静态
- 现有多模态搜索忽略图像局部信息

### 3.2 核心贡献
- 多轮、自适应图文搜索
- 裁剪图像搜索（Grounding DINO）
- 统一多模态工具调用框架

### 3.3 数据集
- DeepMMSearchVQA
- 支持多轮、多模态搜索与推理

### 3.4 实验结论
- 知识密集型 VQA 性能显著提升
- 简单任务中引入搜索可能带来噪声



## 四、总结

两项工作共同展示了：
- 强化学习在 Agent 工具调用与推理策略中的关键作用
- 从“被动回答”到“主动研究”的能力跃迁
- 深度搜索与多模态理解将是下一代智能体的重要方向
