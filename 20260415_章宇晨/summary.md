# 以 CLIP 和 BLIP-2 为主线的多模态视觉语言模型回顾

# 一、VLM 发展背景与技术演进

## 1.1 视觉语言模型的发展阶段

视觉语言模型（Vision-Language Model, VLM）的发展大致经历了三个阶段：

### （1）传统阶段（2018 年前）

以 CNN + RNN 的模块化拼接为主，模型通常只能完成单一任务，例如：
- 图像描述
- 图文检索
- 基础视觉问答

**特点：**
- 一个模型只做一类任务
- 通用性弱
- 泛化能力差
- 难以迁移到新任务

---

### （2）预训练阶段（2018–2022）

随着 Transformer / BERT 架构成熟，以及大规模图文数据出现，VLM 开始进入以**预训练为核心**的发展阶段。

**代表特征：**
- 从单任务训练转向多任务统一建模
- 通过大规模图文预训练实现跨模态对齐
- 首次具备零样本分类、VQA、视觉定位等能力

这一阶段的核心意义在于：

**模型能力主要来自大规模预训练，而不是来自某个具体任务本身。**

---

### （3）大模型阶段（2022 年后）

当前主流路线是：

**视觉编码器 + 大语言模型（LLM）+ 连接模块**

其核心目标不再只是“图文对齐”，而是：
- 让模型真正“看懂图像”
- 接入 LLM 的生成能力
- 支持指令跟随、复杂推理、开放交互与工具调用

---

## 1.2 关键技术主线

从这条演进路径来看，可以将多模态模型的发展概括为：

- **CLIP**：解决“图像与文本如何对齐”的问题
- **BLIP-2**：解决“视觉信息如何高效接入 LLM”的问题
- **更现代的 MLLM（如 Qwen-VL）**：在统一框架下实现开放式多模态理解与交互

---

# 二、CLIP：大规模图文对齐的奠基模型

## 2.1 方法背景与核心动机

CLIP（Contrastive Language-Image Pre-training）由 OpenAI 提出，是多模态预训练时代最具代表性的工作之一。

其核心动机是同时解决两个问题：

1. **多模态表示学习**
2. **跨模态语义对齐**

具体来说，就是把图像和文本编码到同一个共享语义空间中，并通过对比学习显式建立它们之间的对应关系。

---

## 2.2 CLIP 的关键意义

相较于传统 ImageNet 分类模型，CLIP 不再依赖固定类别标签，而是使用自然语言作为监督信号。

这带来了三个关键变化：

### 1. 监督形式更开放
- 不再局限于预定义类别集合
- 自然语言可以表达更丰富的语义

### 2. 模型具备开放词汇能力
- 能处理训练时未明确标注的新概念
- 更适合开放场景理解与检索

### 3. 奠定现代 VLM 基础
- 确立了“大规模图文预训练 + 跨模态对齐”的核心范式
- 为后续 BLIP-2、LLaVA、GPT-4V 等模型提供基础表征能力

---

## 2.3 CLIP 的模型结构

CLIP 采用双塔结构：

| 模块 | 功能 |
| ---- | ---- |
| Image Encoder | 将图像编码为向量表示 |
| Text Encoder | 将文本编码为向量表示 |

训练时，输入是一批对齐的图文对：
- 图像经过图像编码器得到图像向量
- 文本经过文本编码器得到文本向量

随后计算一个 batch 内所有图像与文本之间的相似度矩阵，通过对比学习使：
- 正样本图文对相似度更高
- 负样本图文对相似度更低

---

## 2.4 文本编码器

CLIP 的文本编码器通常采用 Transformer。

主要流程如下：

1. 使用 **BPE** 对文本进行 token 化
2. 在序列两端加入特殊标记 `[SOS]` 和 `[EOS]`
3. 将 token 序列输入 Transformer
4. 取最高层在 `[EOS]` 位置上的输出作为整句语义表示
5. 通过线性投影映射到共享语义空间

这样可以得到一句自然语言描述的全局压缩表示。

---

## 2.5 图像编码器

CLIP 的图像编码器是可替换的视觉 backbone，论文中验证了两类主流结构：

- ResNet
- Vision Transformer（ViT）

这说明 CLIP 的核心不依赖某一种特定视觉结构，而在于：

**是否能通过大规模图文对比学习实现跨模态共享语义空间。**

---

## 2.6 训练方法：InfoNCE 对比学习

CLIP 训练使用大规模图文对数据集 **WIT（WebImageText）**，规模约为 **4 亿组图文对**。

损失函数采用双向对比学习损失（InfoNCE）：

### （1）图像 → 文本
给定图像，在 batch 中找到其对应文本。

### （2）文本 → 图像
给定文本，在 batch 中找到其对应图像。

最终总损失为两者平均。

其本质是：

**把匹配的图文拉近，把不匹配的图文拉远，从而学习统一的多模态语义空间。**

---

## 2.7 推理方式：零样本分类

CLIP 的一个核心能力是 **Zero-shot Classification**。

具体流程如下：

1. 将所有候选类别写入 prompt 模板中  
   例如：`a photo of a <label>`
2. 用文本编码器将这些候选文本编码成向量
3. 将输入图像编码成图像向量
4. 计算图像向量与所有候选文本向量的相似度
5. 得分最高的文本对应预测类别

这相当于把分类问题转化为：

**“给图片找最匹配的文本描述”**

相比直接使用类别名，prompt 化后通常表现更好，在 ImageNet 上可带来明显提升。

---

## 2.8 CLIP 的适用任务与局限

### 适合的任务
凡是能够转化成“图文匹配”的任务，CLIP 都较适合，例如：

- 零样本图像分类
- 场景识别
- 动作识别
- 地理定位
- 图搜文 / 文搜图
- 跨模态检索

### 局限性
CLIP 也存在明显边界：

- 仍依赖候选类别集合
- 不擅长开放式自由生成
- 不适合精细定位类任务（如检测、分割）
- 更偏“匹配与检索”，而非“生成与推理”

---

## 2.9 实验结论

根据 PPT 总结，CLIP 的实验体现出两点核心优势：

### 1. 更强的广义语义表征
在多个下游任务中，CLIP 特征优于传统监督学习特征，尤其在：
- OCR
- 场景识别
- 地理定位
- 动作识别

等任务上表现突出。

### 2. 更强的分布外鲁棒性
在原始分布与分布变化测试集之间对比时，CLIP 精度下降更小，说明其泛化能力更强。

# 三、BLIP-2：把视觉能力高效接入大语言模型

## 3.1 背景与核心问题

CLIP 解决了“图文如何对齐”的问题，但它本质上仍然偏重于匹配与检索，不能直接支持复杂生成任务。

随着大语言模型能力增强，新的问题变成了：

**如何把预训练好的视觉模型和预训练好的语言模型高效连接起来？**

这就是 BLIP-2 要解决的核心问题。

---

## 3.2 BLIP-2 的基本思想

BLIP-2 的核心策略是：

- 冻结预训练图像编码器
- 冻结预训练大语言模型
- 只训练中间的轻量桥接模块

这样既能复用强大的单模态模型能力，又避免了端到端训练的高昂成本。

---

## 3.3 BLIP-2 框架结构

BLIP-2 的核心组成可以概括为：

| 模块 | 功能 |
| ---- | ---- |
| Frozen Image Encoder | 提取图像高维特征 |
| Q-Former | 压缩并筛选视觉信息 |
| Frozen LLM | 基于视觉条件进行文本生成 |

整体目标分为两个层面：

1. **图文表示学习**
2. **视觉到语言生成学习**

---

## 3.4 为什么需要 Q-Former

如果直接把视觉编码器输出的大量 visual tokens 输入 LLM，会面临两个问题：

### （1）视觉 token 数量过多
- 冗余信息很多
- 计算成本高
- 并非所有视觉信息都与当前生成任务相关

### （2）视觉与文本模态空间不一致
- LLM 只在文本上预训练过
- 无法天然理解视觉特征
- 直接连接会导致对齐成本过高

因此 BLIP-2 在中间引入 Q-Former，用来完成：

- 视觉信息筛选
- 视觉特征压缩
- 视觉到语言的桥接

---

## 3.5 Q-Former 的核心作用

Q-Former 是 BLIP-2 的关键创新模块。

其主要思想是：

使用一组**可学习的 query token**，主动从图像编码器输出的海量视觉特征中提取最有用的信息，并压缩成固定长度的表示。

在 PPT 中，其核心形式可以概括为：

- 初始化固定数量的 query（如 32 个）
- 通过交叉注意力与图像特征交互
- 经过训练后，这些 query 会演化为最能代表图像内容的压缩视觉表示

因此，Q-Former 的本质不是完整保留所有视觉信息，而是：

**提炼出最适合后续语言模型使用的关键视觉信息。**

---

## 3.6 图文表示学习阶段

在第一阶段中，BLIP-2 主要训练 Q-Former，让它学会从冻结视觉编码器中抽取高质量视觉表示。

### 输入
- 图像编码器输出的视觉特征
- 可学习 query
- 图像对应文本描述

### 目标
让 query 学会表示图像中最关键、最有语言价值的信息。

---

## 3.7 Q-Former 的训练目标

PPT 中总结了三个训练目标：

### （1）Image-Text Matching（图文匹配）
目的：
- 让 query 与文本充分交互
- 学习文本相关的细粒度视觉信息

特点：
- query 与 text 在 self-attention 中双向可见
- 输出用于二分类，判断图文是否匹配

---

### （2）Image-grounded Text Generation（基于图像的文本生成）
目的：
- 让 query 包含足以支持语言生成的视觉条件信息

特点：
- query 只读取图像
- 文本 token 可以读取 query 和历史文本
- 用真实描述文本做监督，自回归训练

这一目标本质上是在为后续 LLM 生成阶段做准备。

---

### （3）Image-Text Contrastive Learning（图文对比学习）
目的：
- 让 query 表示与正确文本表示更接近
- 不匹配图文更远

特点：
- 与 CLIP 类似，也是在做图文对齐
- 但这里的核心对象变成了 Q-Former 输出的 query 表示

---

## 3.8 视觉到语言生成学习

在第二阶段中，BLIP-2 的目标从“学会压缩视觉信息”进一步转向：

**让冻结的 LLM 能真正理解这些视觉表示。**

基本流程如下：

1. Q-Former 输出压缩后的 query 表示
2. 通过全连接层（FC）投影到 LLM 的 embedding 空间
3. 将这些投影结果作为 **visual prompts**
4. 与文本 prompt 拼接后送入 LLM
5. 用语言建模损失训练 Q-Former 与投影层

---

## 3.9 两类 LLM 接入方式

BLIP-2 支持两类语言模型：

### （1）Decoder-only LLM（如 OPT、GPT）
- 将视觉提示作为前缀
- 与文本 prompt 拼接
- 通过自回归方式生成目标文本

### （2）Encoder-Decoder LLM（如 FlanT5）
- query 与前缀文本共同输入 encoder
- decoder 生成目标文本

这说明 BLIP-2 是一个通用连接框架，而不是绑定某个特定 LLM。

---

## 3.10 BLIP-2 的方法价值

BLIP-2 的重要意义可以概括为四点：

### 1. 轻量模块连接强单模态模型
不需要重新训练完整视觉模型和语言模型，只训练中间桥接层，成本低、效率高。

### 2. 视觉信息压缩
通过 Q-Former 压缩原始视觉 token，减少冗余，提高视觉信息进入 LLM 的效率。

### 3. 适合资源受限和垂直领域
对于医疗影像、工业检测、文档理解等数据少、算力有限的场景尤其有现实意义。

### 4. 为现代 MLLM 提供原型
形成了现代多模态大模型的经典结构范式：

**视觉编码器 → 跨模态适配模块 → 大语言模型**

---

## 3.11 实验结论

根据 PPT 中的实验总结，BLIP-2 展现出两个鲜明优势：

### 1. 更高的训练效率
相比 Flamingo 等方案，BLIP-2 训练参数更少，但性能更强，说明其桥接设计非常高效。

### 2. 强可扩展性
接入更强的视觉编码器或更强的语言模型时，性能还能继续提升。

这表明 BLIP-2 更像是一个**通用多模态连接框架**，而不是仅适用于某一组具体模型。

---

# 四、整体对比与总结

## 4.1 CLIP 与 BLIP-2 的关系

| 模型 | 核心问题 | 核心能力 |
| ---- | -------- | -------- |
| CLIP | 图文如何对齐 | 跨模态匹配、检索、零样本分类 |
| BLIP-2 | 视觉如何接入 LLM | 图像理解 + 文本生成 + 多模态桥接 |

---

## 4.2 技术演进主线

从 CLIP 到 BLIP-2，VLM 的发展体现出一个清晰趋势：

### 第一阶段
先让模型学会：
- 图像和文本在同一语义空间中对齐

### 第二阶段
再让模型学会：
- 把图像信息高效传递给语言模型
- 利用 LLM 完成生成、问答与推理

因此，多模态模型的发展重点已经从：

**“图文匹配”**

逐步转向：

**“视觉条件下的通用语言生成与交互”**

---

## 4.3 总结一句话

如果用一句话概括这条技术主线，就是：

**CLIP 解决了图文对齐，BLIP-2 解决了视觉接入 LLM，它们共同构成了现代多模态大模型的重要基础。**
